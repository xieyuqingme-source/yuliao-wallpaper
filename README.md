# 雨聊壁纸

本地优先的 Windows 壁纸工具：导入喜欢的图片，或低频获取 Wikimedia Commons 开放许可图片，再按自己设定的间隔换图。中文界面，支持托盘操作，不需要账号，不上传本地图片。

**v0.2.0 是测试版 / pre-release。** 148 项后台测试中 147 通过、1 项因 Windows 符号链接权限跳过。真实 GUI、DPI 显示、托盘交互、实际换图和恢复尚未人工验收，请按测试版试用。

## 下载与启动

在 [Releases](https://github.com/xieyuqingme-source/yuliao-wallpaper/releases/tag/v0.2.0) 查找 `YuliaoWallpaper-v0.2.0-windows-x64.zip` 和 `SHA256SUMS.txt`。若该版本尚无附件，可按下方源码步骤运行。

便携版面向 **Windows 10/11 x64**。解压整个文件夹，双击 `YuliaoWallpaper.exe`；不要只移动其中一个 exe。包内带 Python、Tk、Pillow、许可证和对应源码材料，无需安装 Python。Microsoft VC++ x64 运行库使用系统已安装版本，不随本包再分发；若缺少该运行库，请按 [微软官方说明](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist) 自行安装适用的 x64 版本。测试版未进行代码签名，可先核对 SHA-256。

源码运行需要带 Tcl/Tk 的完整 [CPython 3.11](https://www.python.org/downloads/windows/)。在源码根目录打开 PowerShell：

```powershell
.\start.cmd -Setup
```

该明确初始化命令在项目内建立 `.venv`，从官方 PyPI 安装固定版本依赖，随后启动。以后双击 `start.cmd` 即可。启动脚本只为当前 PowerShell 进程设置执行策略，不修改全局策略。没有完整便携包时，GitHub 自动生成的源码 ZIP 本身不含 exe。

## 第一次试用

1. 自行暂停其他壁纸软件，避免同时换图；本工具不会关闭或卸载它们。
2. 在“来源与设置”选择“仅本地图片”和“手动”，保存设置。
3. 在“我的图库”导入选定图片或文件夹，也可“载入内置示例”。预览不会改桌面。
4. 选中一张，点击“启用 / 应用”。程序先保存可恢复的原壁纸及显示设置，备份失败则拒绝修改。
5. 结束试用时点击“恢复原壁纸”，再从托盘“退出”；关闭窗口可能只是收起到托盘。

应用每次启动都等待主动启用。新旧版本共用实例锁，切换版本前请自行退出正在运行的版本。

## 功能

| 功能 | 用法 |
| --- | --- |
| 本地图片 | 单图、多图、指定文件夹当前层导入；不扫描子文件夹、不修改原图，支持相册和标签。 |
| 在线与混合 | 从手工选择的 Commons 类别获取候选，逐图筛选横向尺寸、作者与明确许可；本地、在线缓存或混合可选。 |
| 多主题 | 自然风景、城市建筑、动物、太空天文、科学技术、海洋海岸、花卉植物、山川雪峰；任一选中主题符合即可。 |
| 下载数量 | 默认 10 张，可选 4/10/20 或自定义 1–30 张；候选随机化，可能用现有缓存补足，结果不保证全部为新图。 |
| 换图间隔 | 手动、5/15/30/60 分钟、每天或自定义 5–10080 分钟；暂停、恢复、上一张、下一张。 |
| 独立下载频率 | 手动、每 6 小时或每天；调整下载参数不重置换图计时。暂停换图不停止独立下载。 |
| 图库管理 | Ctrl / Shift 多选；上移/下移调整列表顺序，自动轮换保持随机；收藏、屏蔽、移除和恢复。 |
| 保存选中图片 | 选择目标文件夹，仅复制明确选中的图片，避免覆盖同名文件，并生成作者/来源/许可的 Markdown 和 JSON 清单。 |
| 取消任务 | 下载、导出可取消，保留已完成部分，删除未完成的副本；阻塞网络读取可能需等当前 15 秒超时。 |

图库移除是可撤销的软删除，不删除原图或缓存；刷新不会自动复活已移除图片，收藏仍保留。勾选“显示已移除”后可“恢复选中”。本地导入引用原位置，移动原图会使记录失效。导出最多 500 张/500 MiB，清单不写入原图片绝对路径；清单写入失败会提示。

下载每主题每 6 小时最多启动一次刷新任务；所有主题合计最多 20 个 API 小批次、240 个候选槽位和 120 MiB 响应读取（含重试）。单图最多 12 MiB，缓存硬上限 200 MiB；不自动删除旧缓存腾空间。软移除不释放缓存空间。

失败保留当前桌面，断网可用缓存。睡眠唤醒最多执行一次到期换图，重新计时，不集中补执行。图库候选用完后长期轮换仍会再次出现。

## 图片来源与许可

自动下载只使用 [Commons imageinfo API](https://www.mediawiki.org/wiki/API:Imageinfo)，遵守 [API etiquette](https://www.mediawiki.org/wiki/API:Etiquette)，使用识别应用和项目的 User-Agent、串行请求、缓存、限额和退避。HTTPS 允许域、重定向、MIME、字节、像素和实际解码均有校验；元数据净化为文字，不执行其中内容。

**Commons 不等于 CC0。** 本版接受能明确识别的公有领域、CC0、CC BY 和 CC BY-SA；未知许可跳过。科技主题为电子元件、机器与工程，太空主题为 NASA、Hubble 和天文候选，不提供 AI 科幻生成，也不因 NASA 类别就假定每张都无版权。

“作者与许可”显示作者、来源页、许可链接和裁切说明。图片公开再利用仍须遵守该图具体许可和其他适用权利要求；参见 [Commons REUSE](https://commons.wikimedia.org/wiki/Commons:REUSE)。缓存或本地图包不随源码和发布附件分发。

“推荐网站”只在用户点击时打开默认浏览器，工具不会从这些入口抓取图片：

- [必应](https://www.bing.com/)：只使用官方提供的下载入口和说明。
- [NASA 地球壁纸](https://science.nasa.gov/gallery/landsat-virtual-backgrounds-and-wallpapers/)：查看具体图片署名与条款。
- [Commons 精选](https://commons.wikimedia.org/wiki/Featured_pictures)：逐图核对许可。
- [Met 开放馆藏](https://www.metmuseum.org/hubs/open-access)：选择明确标有 OA / CC0 的开放图像。

本版不自动抓取 Bing，不接入 Unsplash/Pexels 壁纸 API。自行合法取得的图片可本地导入。

## 隐私与限制

私人配置、导入记录、缓存、日志、渲染副本和原壁纸备份保存在 `%LOCALAPPDATA%\YuliaoWallpaper`，不应上传到仓库或作品网站。本工具不上传本地照片、不扫描整个图片盘；在线获取会向 Wikimedia 发出正常网络请求。

- 真实启用和恢复要求 **一个活动显示器**，多屏会安全拒绝；不支持各屏独立背景。
- 恢复静态壁纸及填充/平铺设置，不恢复第三方动画、幻灯片计划或锁屏。
- 原壁纸不可读时，仅在能确认 Windows 缓存对应当前原图时采用副本；未知缓存格式或备份失败则拒绝启用。
- 成功恢复后归档旧基准，下次启用重新备份。不要直接删除私人目录，否则会丢失恢复能力和收藏。
- 旧配置首次保存前保留 `config.pre-0.2-*.json`；迁移备份失败时不覆盖原配置。
- 不支持账号、服务器、云同步、AI 生图和开机自启。未做长期实际桌面或新版批量联网验收。
