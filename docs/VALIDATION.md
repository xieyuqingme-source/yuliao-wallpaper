# v0.2.0 测试版验证范围

环境：Windows 11 x64、CPython 3.11.4、Tk 8.6、Pillow 12.3.0、pystray 0.19.5、PyInstaller 6.22.3。固定依赖在仓库清单中。

148 项后台测试：147 通过，1 项仅因当前 Windows 账号没有创建符号链接权限跳过。所有实际换壁纸调用均使用模拟对象，所有界面逻辑测试使用假控件。

- 37 项 Commons 测试：多主题、数量、候选随机化、20 批次/240 槽位/120 MiB 限额、取消、退避、缓存复用、许可、MIME、图片解析及路径边界。
- 22 项存储测试：迁移、首存备份、排序、移除/恢复、收藏与屏蔽保留；含权限跳过项。
- 11 项导出测试：明确选择、不覆盖、原图保留、资源限额与无原始路径的署名清单。
- 32 项轮换及 20 项 Windows 适配测试：手动与五分钟下限、频率独立、睡眠、历史、失败保留桌面、备份与恢复。
- 22 项界面逻辑和 4 项入口测试：多选、取消、计时、布局边界、官网链接白名单与异常收尾。

Python 编译和依赖检查通过，便携包仅执行不建窗口的 `--self-check`。公开包使用净化的子进程构建环境，不包含个人图片、下载缓存、私人配置、日志或开发历史。

**未人工验收：**真实 GUI 和高 DPI、托盘/文件选择/取消交互、Windows 10 实际运行、真实桌面换图与恢复、新版批量下载、长时间轮换和真实断网。类别存在性已通过官方页面核查；模拟测试不代表服务保证凑满目标张数。

因此 v0.2.0 按 pre-release 发布，欢迎在上述范围内试用并提供移除个人信息的反馈。
